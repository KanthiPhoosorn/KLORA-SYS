# Thai subdistricts (ตำบล / แขวง) with centroids and postcodes

Used offline to place a recipient address for the transport distance (`src/lib/tambon.ts`,
`src/lib/tambon-data.json` generated by `scripts/gen-tambon.mjs`).

Source: **Thailand Canonical Administrative-Names Reference** v1.0.0 by William J. Reynolds —
https://github.com/DevelopedbyWill/thailand-canonical-admin-names (DOI 10.5281/zenodo.20049930),
files `data/v1.0.0/thailand-adm1-provinces-v1.0.0.csv`, `thailand-adm2-districts-v1.0.0.csv`,
`thailand-adm3-subdistricts-v1.0.0.csv` (saved here as `adm1.csv`, `adm2.csv`, `adm3.csv`, unmodified).

Licence: CC BY 4.0 (`LICENSE-DATA.txt`, https://creativecommons.org/licenses/by/4.0/). Upstream
attributions are in `NOTICE.md`.

Changes made for Corta: only the Thai names, postcodes and centroid coordinates are kept, joined into one
compact JSON (coordinates rounded to 4 decimals); 14 subdistricts without a centroid use their district's.
