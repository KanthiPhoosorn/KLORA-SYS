## 1. สูตรหลัก — CO₂e ต่อดอก

```
CO₂e ต่อดอก = ( คาร์บอนจากการปลูก + คาร์บอนจากการขนส่ง + คาร์บอนจากตะกร้า )
              ÷ จำนวนดอกไม้ในรอบนั้น
```

แยกเป็น 3 ก้อน:

| ก้อน | สูตร |
|---|---|
| **การปลูก** | `(น้ำมัน L × 2.68) + (ไฟฟ้า kWh × 0.5) + (ปุ๋ย kg × 1.3)` |
| **การขนส่ง** | `ระยะทาง km × 0.2` |
| **ตะกร้า** | `Σ ( 2.0 ÷ จำนวนครั้งที่ตะกร้าใบนั้นถูกใช้ )` |

> **ตะกร้าหมุนเวียน:** ระบบนับเองว่าตะกร้าแต่ละใบถูกใช้กี่รอบ แล้วหารเฉลี่ยคาร์บอนการผลิตตะกร้าตามจำนวนครั้ง
> — ใช้ซ้ำยิ่งมาก คาร์บอนต่อรอบยิ่งต่ำ (สะท้อนแรงจูงใจการใช้ซ้ำจริง)

### ค่า Emission Factor ที่ใช้

| รายการ | ค่า | หน่วย |
|---|---|---|
| น้ำมันดีเซล | 2.68 | kg CO₂e / ลิตร |
| ไฟฟ้า (กริดไทย) | 0.5 | kg CO₂e / kWh |
| ปุ๋ย | 1.3 | kg CO₂e / kg |
| ตะกร้า (การผลิต 1 ใบ) | 2.0 | kg CO₂e / ใบ |
| ขนส่ง (รถบรรทุกเล็ก) | 0.2 | kg CO₂e / km |

อ้างอิงกรอบค่า Emission Factor (CFO) จาก **TGO — องค์การบริหารจัดการก๊าซเรือนกระจก**
(https://thaicarbonlabel.tgo.or.th/)

> ⚠️ **ข้อควรทราบ:** ค่าข้างต้นตั้งตามแนวทาง TGO/IPCC แต่ยังไม่ใช่ตัวเลขทางการรายค่าล่าสุดของ TGO
> (ค่าจริงอยู่ในไฟล์ PDF แนบของ TGO) — แก้ได้ที่เดียวใน `src/lib/carbon.ts` (`FACTORS`)
> แนะนำให้ยืนยันค่ากับ TGO ก่อนใช้อ้างอิงเชิงพาณิชย์

## 2. สูตรรอง

**ความสดหลังตัด (อายุดอกไม้)**
```
ageDays = วันที่ลงข้อมูล − วันที่ตัด        (ไม่ติดลบ)
```

**ระยะทางขนส่ง (ประมาณอัตโนมัติ)**
```
ถ้ารู้พิกัด GPS ฟาร์ม : ระยะทาง = haversine(ฟาร์ม → ปลายทาง) × 1.3
ถ้าไม่รู้พิกัด        : ใช้ค่า default ของปลายทางนั้น
```
`1.3` = ตัวคูณแปลงระยะเส้นตรงเป็นระยะถนน · ปลายทางที่มีในระบบ: กรุงเทพฯ 785, เชียงใหม่ 95,
เชียงราย 30, พะเยา 95, ขอนแก่น 480, นครราชสีมา 615, ชลบุรี 870, ภูเก็ต 1650, หาดใหญ่ 1580 (km)

**สัดส่วนที่มาของคาร์บอน** (ใช้ในแดชบอร์ด/รายงาน) = รวมแต่ละก้อนข้ามทุกรอบ แล้วคิด % ของผลรวม

## 3. ข้อมูลที่ระบบเก็บ

### ผู้ผลิต / ฟาร์ม (Supplier — `SUP-YYYY-NNNN`)
- **บังคับ:** ชื่อฟาร์ม · ที่อยู่ · จังหวัด · พิกัด GPS · เจ้าของ · ประเภทดอกไม้ · จุดเด่นฟาร์ม · ช่องทางติดต่อ
- **ใช้คำนวณ:** น้ำมัน (ลิตร/รอบ) · ไฟฟ้า (kWh/รอบ) · ปุ๋ย (kg/รอบ) · สารเคมีเกษตร · น้ำ (ลบ.ม.) · ของเสีย (kg) · จำนวนดอก/เดือน
- **อื่น ๆ:** ผู้ติดต่อ · เบอร์โทร · Line ID · พันธุ์ที่ปลูก · คำโปรย/การดูแล/รูป (สำหรับหน้า passport) · แพ็กเกจ (free/pro) · สถานะ (ใช้งาน/ระงับ)

### รอบการส่งออก (Batch — `BAT-YYYY-NNNN`)
- จำนวนดอกไม้ · พันธุ์ · วันที่ตัด · วันที่ลงข้อมูล
- ปลายทาง · ระยะทาง (km) · รูปแบบขนส่ง · รหัสไปรษณีย์ · สาขาที่นำส่ง
- บรรจุภัณฑ์ (วัสดุในกล่อง) · น้ำหนักรวม · **หมายเลขตะกร้าที่ใช้ (หลายใบได้)**
- **ผลคำนวณ:** CO₂e ต่อดอก · อายุหลังตัด (วัน)
- **สถานะคำนวณ:** ร่าง → ส่งแล้ว → คำนวณแล้ว · **สถานะขนส่ง:** ตัดดอก → ระหว่างขนส่ง → ส่งถึง

### บัญชีผู้ใช้ (User — `USR-NNNN`)
บทบาท (ฟาร์ม / ขนส่ง / KYN) · อีเมล · ชื่อผู้ใช้ · **ชื่อบริษัท + สาขา** (บัญชีขนส่ง) ·
รหัสผ่านเข้ารหัสแบบ scrypt (เก็บเป็น hash + salt ไม่เก็บรหัสจริง)

### อื่น ๆ
- **บันทึกการพิมพ์ QR** (`PRT-NNNN`): SUP ID · รอบ · ปลายทาง · ผู้พิมพ์ · จุดคัดแยก · เวลา · สถานะยกเลิก
- **ทีมงาน / คำเชิญ** (`MEM-`/`INV-`) · **การแจ้งเตือน** · **OTP** รีเซ็ตรหัสผ่าน (หมดอายุ 10 นาที)

## 4. ใครทำอะไรในระบบ

```
ฟาร์ม            KYN                    ขนส่ง                ผู้บริโภค
กรอกรอบส่งออก →  รับข้อมูล + กดคำนวณ →   ค้นหา + พิมพ์ QR →   สแกน QR ดู passport
                 (CO₂e เกิดขึ้นตรงนี้)                        (CO₂e/ดอก + ความสด + ที่มา)
```

**จุดสำคัญ:** ค่า CO₂e **ไม่ได้** คำนวณตอนฟาร์มกรอกข้อมูล แต่คำนวณตอน **KYN กดคำนวณ**
ตาม flowchart ที่ออกแบบไว้ (ฟาร์มกรอก → KYN ตรวจ+คำนวณ → ขนส่งพิมพ์ QR)

## 5. สรุปตัวอย่างการคำนวณ

ฟาร์มใช้ น้ำมัน 15 L · ไฟฟ้า 40 kWh · ปุ๋ย 20 kg · ส่ง กรุงเทพฯ 785 km · ใช้ตะกร้า 2 ใบ (ใบละใช้มาแล้ว 4 รอบ) · 1,000 ดอก

```
ปลูก    = 15×2.68 + 40×0.5 + 20×1.3   = 40.2 + 20 + 26   = 86.2  kg
ขนส่ง   = 785 × 0.2                                        = 157.0 kg
ตะกร้า  = (2.0÷4) × 2 ใบ                                   = 1.0   kg
รวม                                                        = 244.2 kg
CO₂e ต่อดอก = 244.2 ÷ 1,000                                = 0.2442 kg/ดอก
```
