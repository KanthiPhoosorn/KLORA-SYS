## A. สูตรฉบับสมบูรณ์ที่ KYN ต้องการ

```
Total_Order_Carbon = CO2e_Farm + CO2e_Packaging + CO2e_Transport
Carbon_Per_Stem    = Total_Order_Carbon ÷ จำนวนดอกไม้ในออเดอร์
```

### A1. CO2e_Farm — คิดจาก "น้ำหนักดอกไม้สุทธิ"
```
Net_Flower_Weight = น้ำหนักพัสดุที่ชั่งจริงก่อนส่ง − น้ำหนักบรรจุภัณฑ์รวม
CO2e_Farm         = Net_Flower_Weight × Dynamic_Flower_EF
```
**Dynamic_Flower_EF** คิดจากข้อมูลรายเดือนของฟาร์ม (ตาราง `farm_monthly_inputs`):
```
Total_Farm_Carbon = diesel_L×2.68 + kWh×0.4999 + ปุ๋ย_kg×3.50
                  + สารเคมี_kg×10.00 + น้ำ_m³×0.16 + ของเสีย_kg×0.55
Dynamic_Flower_EF = Total_Farm_Carbon ÷ total_flower_yield_kg   (kg CO2e / kg ดอกไม้)
```
**Fallback:** ถ้าไม่มีข้อมูลฟาร์ม หรือ yield ≤ 0 → ใช้ค่ากลาง **0.65**

### A2. CO2e_Packaging — คิดจากมิติ W×L×H (ไม่ใช่ค่าคงที่ต่อใบ)
| ประเภท | สูตร |
|---|---|
| กล่องลูกฟูก | `Area = 2[(W×L)+(W×H)+(L×H)] ÷ 10,000` → `Weight = Area × 1.2 × 0.55 × qty` → `Carbon = Weight × 0.86` |
| แผ่นพลาสติก/ซอง | `Area = (W×L) ÷ 10,000` → `Weight = Area × 1.0 × 0.04 × qty` → `Carbon = Weight × 2.75` |

(W,L,H หน่วย cm · 1.2/1.0 = Safety factor เผื่อลิ้นกล่อง · ถ้า H=0 ให้คิดแบบ 2 มิติ)

### A3. CO2e_Transport — 2 รูปแบบตามมาตรฐาน TGO
```
รูปแบบ 1 (แนะนำ): น้ำหนัก gross (ตัน) × ระยะทาง (km) × EF_tkm
รูปแบบ 2:         ระยะทาง (km) × EF_vkm
ถ้าใช้ตู้แช่เย็น (is_reefer_used) → คูณเพิ่ม × 1.15
```

### 🔴 2 เรื่องที่ต้องแจ้ง KYN

(ค่าอื่นในตารางเดียวกัน: CFP grid mix 2022-2024 = 0.5562 · Scope 3 fuel supply = 0.0812)

**2. ดีเซล 2.68 เป็นค่า CO2-only ไม่ใช่ CO2e**

### ❗ TGO ไม่มีค่า ton-km / vehicle-km
ตรวจทั้งเอกสารแล้ว **ไม่มีสักแถว** — ตาราง CFO ของ TGO คิดตาม "ปริมาณเชื้อเพลิง" ไม่ใช่ "งานขนส่ง"
ดังนั้นค่า `EF_tkm` / `EF_vkm` ที่สเปกขอ **อ้างจาก TGO ตรง ๆ ไม่ได้** — `src/lib/transport-ef.ts`
จึงคำนวณให้แบบโปร่งใส:
```
EF_vkm = อัตราสิ้นเปลือง (ลิตร/กม.) × EF เชื้อเพลิง [TGO]
EF_tkm = EF_vkm ÷ น้ำหนักบรรทุกเฉลี่ย (ตัน)
```
**ค่าเชื้อเพลิงเป็นทางการ · อัตราสิ้นเปลืองกับน้ำหนักบรรทุกเป็นค่าสมมติ** (ติดธง `assumption: true`)
→ ขอค่าจริงจากฟลีตของ KYN มาแทนได้ทันที แก้ที่ `VEHICLE_PROFILE` ที่เดียว
